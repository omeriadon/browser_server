# Astra AI documentation

Astra has one feature interface for Apple Intelligence on-device and
OpenRouter through its authenticated server. Both providers support single
responses and streaming.

- [AI system overview](ai-features.md)
- [Adding a feature](ai/adding-features.md)
- [Streaming and single responses](ai/streaming.md)
- [Server API and deployment](server-api.md)
- [Astra app source](https://github.com/omeriadon/astra)
- [Server source](https://github.com/omeriadon/browser_server)

These docs describe the AI-system worktree. App-side changes must be integrated
into Astra before the new manager APIs are available in a released app.
